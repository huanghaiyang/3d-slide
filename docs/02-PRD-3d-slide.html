PRODUCT REQUIREMENTS · P0 MVP · SPATIAL PRESENTATION

3d-slide 产品需求文档
空间演示，从取景开始

本文档定义 3d-slide P0 的产品行为与业务规则：用户如何在一个连续的三维场景中放置内容、 用相机视点组织叙事、进入演示，以及工作如何被保存、恢复与带走。 技术架构、接口与实现方案不在本文范围内。

01

背景与目标

BACKGROUND & GOALS

线性演示把空间关系压平成页面顺序：层级、对比、流程被切成同样大小的卡片。 空间演示工具本来可以保留这些关系，却把门槛放在了相机与路径编辑上。 3d-slide 的取舍是：内容共同存在于一个连续空间，叙事只由相机视点负责。 用户不需要建模，也不需要写动画时间轴，只需要摆放内容、取好景、按顺序记录。

我们观察到的三件事

观察对用户的影响产品含义
关系被切成页观众记住了顺序，却记不住结构；讲完后脑中缺少一张完整地图。内容必须能同时出现在视野里，缩放与移动应成为主要叙事手段。
相机比画布更吓人非设计用户在三维视图里容易迷路，不知道该飞向哪里、怎么回来。取景必须可捕获、可重置、可聚焦；不要求用户输入相机坐标。
素材与交付常被当作附加项图片、中文排版、离线演示需要用户自己找办法妥协。素材与工程文件是 P0 主路径的一部分，而不是导出时才考虑的事。

目标

ID目标可观察结果
G1首次使用者完成闭环不依赖教程，完成「新建 → 加内容 → 设视点 → 演示」四步，并在每一步知道下一步该做什么。
G2观众感知到连续空间视点切换是相机飞行而非页面淡入淡出；观众能说出「从全景到了局部」。
G3工作不会消失刷新、关闭标签页、重新打开浏览器后，内容与上次编辑视图都可恢复。
G4作品可以带走导出一个 .slide 工程文件，在另一台浏览器中完整打开。
G5用户不会迷路编辑中可一键重置视图或聚焦选中对象；演示中可随时回到当前视点。
NOTE P0 不设定留存、时长、转化等量化指标。目标以「闭环是否走通、结果是否可观察」为准；指标设计不在本阶段范围内。

03

产品模型与核心流程

MODEL & FLOW

3d-slide 不是「每页一个场景」的幻灯片。一个作品只有一个连续空间，所有内容对象同时存在； 视点只是相机在空间中的一次取景快照。翻页不改变内容，只改变你从哪里看。

最小闭环与恢复路径

入口条件是打开首页并新建或打开一个作品。用户完成放置内容、调整取景、捕获视点后进入演示； 演示退出后回到编辑器，自动保存恢复作品。最重要的失败恢复有两条：图片加载失败时提供重试 / 替换 / 删除； 本地保存失败时保留当前编辑状态，并提供重试与导出工程。

RULE 内容对象属于作品而不是视点。删除一个视点不会删除任何内容；新增视点也不会复制内容。任何「每页独立内容」的预期都视为误用，需在界面文案中明确。
04

功能需求

FUNCTIONAL REQUIREMENTS

以下七个模块构成 P0 的完整行为面。每个模块按「目的 → 界面 / 触发 → 处理规则 → 结果与状态 → 异常」组织； 跨模块重复出现的规则统一收敛到第 05 节，模块内只引用编号，不重复定义。

FR-01

作品入口与作品管理

HOME / DECK

目的

让用户从打开页面到进入编辑不超过两步；让「最近作品」成为可信的入口，而不是一个会误删东西的列表。

界面与触发

区域内容与职责
顶栏品牌、「导入」、主按钮「新建演示」。
作品列表按最后修改时间倒序；每项显示标题、缩略占位、更新时间、对象数与视点数。
空状态首次使用时显示「新建第一份演示」与「导入 .slide 文件」两个入口。
作品菜单每张作品卡片提供重命名（进入编辑器后也可改）与删除。

处理规则

1. 新建　点击「新建演示」立即创建一个标题为「未命名演示」的空白作品并进入编辑器；P0 不插入模板或引导页。

2. 标题　编辑器顶栏内联编辑，长度 1–80 字符；失焦时若为空，恢复为上一个有效标题。修改后首页列表同步更新。

3. 最近作品　仅列出本地作品，按最后修改时间倒序；不设数量上限，可显示数量受浏览器本地存储容量约束。

4. 删除　从作品卡片触发，必须经过二次确认。确认框显示作品标题，并明确「删除后无法恢复」。确认后删除作品并返回首页；若该作品正在另一个标签页打开，按 SR-05 处理。P0 不提供回收站。

5. 打开　点击作品卡片进入编辑器，恢复到最后一次保存的编辑视图；选中状态不恢复。作品不存在或数据损坏时见异常。

结果与状态

首页存在三种可见状态：空状态、作品列表、删除确认中。删除完成后列表立即更新，无延迟占位。

异常

触发用户可见行为
作品数据无法读取该作品卡片标记「无法打开」，点击时提示原因；列表其他作品不受影响。
删除确认被取消关闭确认框，不改变任何数据或列表顺序。
标题为空失焦时恢复上一个有效标题，不产生空标题作品。
FR-02

编辑器与空间视图

EDITOR

目的

提供一个稳定的「取景 — 布置」工作台。用户始终能回答三个问题：我在看什么、我选中了什么、我怎么回到原点。

界面布局

区域内容与职责
顶栏返回首页、作品标题、保存状态、撤销 / 重做、「演示」、「导出」。
左栏内容对象列表，按深度从近到远排序；每项显示类型、名称、可见性开关。可折叠。
中央16:9 取景安全框内的空间视图；左上角显示视图工具：重置视图、网格开关、缩放提示。
右栏属性检查器。未选中时显示作品设置（背景色、默认过渡时长、演示进度开关）；选中时显示对象属性。
底部视点轨道，行为见 FR-04。无选中对象时，它承担「下一步」的引导作用。

视图操作

操作触发结果
平移视图在空白处按住左键拖拽相机沿屏幕平面移动，不改变朝向与距离。
环绕视图Alt / Option + 左键拖拽围绕当前看向点旋转相机；不改变看向点的位置。
缩放视图滚轮以光标位置为中心前进 / 后退，保持画面中心目标不漂移。
重置视图工具栏「重置视图」相机回到作品初始正视视角，取景安全框充满视图。
聚焦对象选中对象后按 F 或工具栏按钮相机对准对象中心，对象以完整可见为准并保留边距。
选择 / 取消单击对象 / 单击空白选中单个对象并显示其属性；空白点击取消选中。
删除对象选中后按 Delete / Backspace删除并进入撤销栈，不弹确认。

处理规则

1. 取景一致性　编辑视图始终显示固定 16:9 安全框；窗口更大时安全框居中留边，更小时整体缩放显示。演示按同一安全框取景，不出现编辑看不到、演示被裁掉的内容。

2. 相机不写入作品　常规平移、环绕、缩放只改变当前视图，不改变视点、不影响自动保存的内容结构；仅当用户捕获或更新视点时，相机状态才进入作品。

3. 防止迷路　「重置视图」与「聚焦选中对象」在编辑期间始终可用；二者不进入撤销栈，也不改变内容。

4. 网格　默认开启，作为空间参照；只在编辑中出现，演示中永不渲染。网格间距随缩放自适应，不显示坐标数值。

5. 选择模型　P0 仅支持单项选择；点击对象即切换选择，不提供框选、Shift 多选与批量变换。

6. 视图恢复　离开作品或刷新后，恢复到上次保存的编辑视图（相机与缩放），选中状态清空。

结果与状态

选中对象时：画布显示选框、对象列表高亮、右栏切换为该对象属性。未选中时右栏显示作品设置。视图缩放比例始终可见（如「72%」），但不可直接输入。

异常

触发用户可见行为
空白作品画布中央显示「添加第一个内容」的空状态，提供文本 / 图片 / 形状三个快捷入口；不自动创建对象。
视口宽度小于 1024px顶部显示「建议使用更宽的窗口」提示条；编辑功能保留，不保证所有面板同时可见。
对象达到 200 个上限添加按钮禁用，悬停提示「已达到单作品对象上限」。

    FR-03

    内容对象

    TEXT / IMAGE / SHAPE

    目的

    用三类对象覆盖一次讲解的基本素材：文本负责观点，图片负责证据，形状负责结构。P0 不追求富文本排版与素材管理。

    通用属性

    字段范围 / 规则说明
    名称1–60 字符默认按类型自动命名（文本 1、图片 1、矩形 1）；可在属性面板修改，不要求唯一。
    位置 X / Y场景坐标，−99999 至 99999新对象放在当前视图中心对应的世界坐标。
    深度 Z−10000 至 10000数值越大越靠近观众。新对象默认在当前最靠前对象之上 +10；无对象时为 0。
    尺寸 W / H最小 8；最大 20000文本高度随内容自动增长、不可手动修改；图片与形状宽高可编辑。
    旋转−180° 至 180°（仅 Z 轴）P0 不支持 X / Y 轴倾斜；数值以度为单位，可输入或滑杆调整。
    不透明度0–100%默认 100%；隐藏对象与 0% 透明度是两种不同状态。
    可见开 / 关关闭后对象仍在场景中，编辑视图以半透明占位显示，演示中不渲染。
    图层顺序由深度 Z 推导左侧列表按 Z 从近到远排序；拖拽调整顺序时交换相邻对象的 Z 值，见 SR-01。

    文本

    编辑　双击进入行内编辑；Esc 放弃本次修改，点击空白或 Ctrl / Cmd + Enter 提交。提交空内容时删除该对象，该删除可撤销。

    样式　字体提供四个预设：系统黑体、宋体、圆体、等宽；字号 8–400（默认 48）；支持加粗、左 / 中 / 右对齐、字色与行高 0.8–3.0。一个文本对象只能使用一种字体与字号，P0 不做富文本混排。

    换行与上限　文本按文本框宽度自动换行，高度随行数增长；单对象上限 5000 字符ASSUMPTION，达到上限后禁止继续输入并提示。

    图片

    添加　点击「图片」选择文件，或把文件拖入空间视图；拖入时以落点作为放置位置，否则放在当前视图中心。

    格式与大小　支持 PNG、JPG / JPEG、WebP、GIF；GIF 在 P0 只显示首帧，不作为动图播放。单张 ≤ 20MBASSUMPTION。不支持的格式与超限文件见异常。

    尺寸与适配　默认锁定原始比例，拖拽缩放保持比例；属性面板可解除锁定并允许变形。适配方式提供「完整显示」（默认，留白）与「填充裁切」（铺满对象框）。替换图片时保留位置、尺寸、旋转与深度。

    形状

    提供矩形、椭圆、直线三种。矩形与椭圆支持填充色与描边；直线只有描边、无填充。默认填充使用强调青色，描边关闭；属性面板可修改颜色与描边宽度 0–40。

    对象操作与图层

    添加　工具栏「添加」选择类型；新对象进入选中状态，右栏显示属性，视点轨道同时提示「捕获当前视图作为一个视点」。

    删除　Delete / Backspace 或属性面板删除按钮，不弹确认，进入撤销栈。

    可见性　左栏眼睛图标切换；隐藏对象在编辑器中保留虚线轮廓与半透明内容，演示中完全不渲染。

    层级　左栏拖拽改变前后顺序；系统交换相邻对象的 Z 值而不是插入任意小数，保证顺序稳定、可撤销、可再次还原。

    异常

    触发用户可见行为
    图片解码失败 / 文件损坏对象以占位图显示，提供「重试」「替换」「删除」；其他内容不受影响。
    不支持的文件类型拒绝添加并提示支持的四种格式，不创建占位对象。
    单图超过 20MB拒绝添加并显示实际大小与上限；已存在图片不受影响。
    文本提交为空删除该文本对象（可撤销），不保留空气泡。
    达到 200 对象上限添加入口禁用并提示上限；删除对象后立即恢复可用。
    FR-04

    视点与叙事路径

    FRAMES / PATH

    目的

    把「怎么讲」固化成一条可回放的空间路径。用户只需要摆好画面并捕获，不需要理解相机参数。

    界面与触发

    区域内容与职责
    视点轨道底部横向卡片：序号、名称、过渡时长。当前播放或最近应用的视点高亮。
    添加视点轨道末尾的「＋ 添加视点」，捕获当前编辑器视图。主路径
    视点属性点击卡片后右栏显示：名称、过渡时长、「用当前视图更新」、删除。
    排序拖拽卡片改变顺序，序号自动重排；顺序即演示顺序。

    处理规则

    1. 捕获　添加视点时记录当前相机取景，包括看向点、距离与朝向；由于编辑与演示共用 16:9 安全框，捕获的构图与演示一致。

    2. 更新　选中视点后点击「用当前视图更新」，以当前视图覆盖该视点取景；更新进入撤销栈。名称与过渡时长不受影响。

    3. 前往　点击视点卡片时，编辑器相机以 0.4 秒过渡飞到该视点，便于对照调整；这次移动不写入作品，也不进入撤销栈。

    4. 命名　默认「视点 N」，长度 1–40 字符；清空后失焦恢复上一个有效名称，不允许空名称。

    5. 过渡时长　单个视点可设 0.2–5.0 秒，默认继承作品设置（默认 1.2 秒）。时长属于「被进入的那个视点」：从视点 A 到 B 时使用 B 的时长。改动只影响之后发生的过渡。

    6. 顺序与数量　P0 只支持线性路径，不支持分支、循环或跳转；单作品最多 50 个视点ASSUMPTION，达到上限后添加按钮禁用。

    7. 删除　删除视点不弹确认、不移除任何内容对象，进入撤销栈；删除当前高亮视点后，高亮回到相邻视点，不移动相机。

    8. 零视点　作品允许没有视点。此时仍可从当前视图进入演示，但前进 / 后退禁用，并在轨道处提示「添加视点后可串联叙事」。

    结果与状态

    轨道始终显示所有视点；当前视点由「最近点击或最近捕获」决定。添加 / 更新 / 排序 / 删除后，轨道序号立即重排并随作品自动保存。任何视点操作都不改变内容对象的可见性、深度或层级。

    异常

    触发用户可见行为
    无视点时点击「演示」提示并允许「从当前视图开始」；前进 / 后退按钮禁用。
    名称被清空失焦后恢复上一个有效名称，不产生空名称视点。
    达到 50 个视点上限「添加视点」禁用并提示；删除后可恢复。
    更新视点时相机尚未稳定以当前实际取景为准；不存在「更新失败」状态。

    FR-05

    演示模式

    PRESENT

    目的

    在没有编辑器干扰的环境中完整讲完一条空间路径，并允许讲述者临时离开路径查看细节，再可靠地回到叙事。

    进入与起点

    顶部「演示」触发。若作品已有视点，弹出起点选择：从第一个视点开始（默认）或从当前视图开始；无视点时直接以当前视图进入，并提示「添加视点后可串联叙事」。进入后请求全屏；请求被拒绝时使用全窗口演示，并显示一条可关闭的提示条。

    界面

    演示中只渲染作品内容，不显示左栏、右栏、轨道、网格与选择框。右下角显示视点进度（如「3 / 8」），可在作品设置中关闭；首次进入时显示一次操作提示，3 秒后淡出。光标在 2 秒无操作后隐藏，移动后立即恢复。

    控制

    操作输入行为
    下一个视点单击（未拖动）/ → / Space / Enter相机按目标视点的时长飞向下一个视点；位于末视点时保持不动。
    上一个视点←返回上一个视点；位于首视点时保持不动。
    退出演示Esc退出全屏与演示，回到编辑器；相机停留在最后观看的取景。
    自由浏览按住拖拽（移动超过 4px）围绕当前看向点环绕；滚轮以光标为中心缩放 10%–800%（相对当前视点取景）。不写入作品。
    回到路径双击舞台 / R相机在 0.6 秒内回到当前视点的取景。
    推进确认相机飞行中再次点击忽略该输入，直到本次过渡结束，避免连点跳过多个视点。

    处理规则

    1. 过渡　相机从当前位置飞到目标视点，位置、朝向与距离同时插值，缓入缓出；时长取目标视点的设置。相机飞行期间不接受前进 / 后退输入。

    2. 内容不可交互　P0 中所有内容对象在演示里只作为视觉内容，不支持点击链接、播放视频或选中文字；鼠标点击只用于推进视点。

    3. 自由浏览不污染作品　演示中的缩放与环绕不写回视点、不影响自动保存；退出演示时相机停在最后观看位置，便于继续编辑。

    4. 比例　演示使用与编辑相同的 16:9 安全框；屏幕比例不同时上下或左右留黑，不裁切内容。

    5. 减少动效　系统开启「减少动态效果」时，所有相机过渡改为瞬时切换；该设置只影响呈现，不影响路径数据。

    6. 退出　Esc、系统退出全屏、窗口失焦都不改变作品内容；退出后清空选择状态并恢复编辑器界面。

    结果与状态

    演示状态
    进入全屏→ 路径播放⇄ 自由浏览→ 退出
    当前视点
    首视点→ 中间视点→ 末视点

    异常

    触发用户可见行为
    全屏请求被拒绝全窗口演示 + 顶部提示「浏览器阻止了全屏，按 Esc 退出」；内容与控制不受影响。
    无视点进入演示展示当前视图；前进 / 后退禁用；进度显示「1 / 1」或隐藏。
    过渡中被连续点击忽略后续输入，过渡结束后才接受下一次导航。
    演示中窗口比例变化安全框等比缩放并重新留黑，不裁切内容。
    FR-06

    保存、撤销与恢复

    AUTOSAVE / UNDO

    目的

    让用户敢于直接关闭页面：不需要记得点保存，也不会因为一次误操作丢掉整个作品。

    自动保存

    任何会写入作品的操作停止 2 秒后自动保存ASSUMPTION；页面隐藏、窗口失焦时强制保存一次。保存内容包括作品标题、画布背景与设置、全部内容对象与素材、视点路径、最后一次编辑视图。

    状态顶栏显示说明
    待保存「未保存更改」有改动尚未落盘；通常只存在 2 秒以内。
    保存中旋转图标 + 「保存中」写入期间不接受重复保存请求。
    已保存「已保存 HH:MM」成功后显示时间；无后续改动时保持。
    保存失败红色「保存失败 · 查看」点击查看原因，提供「重试」与「导出工程」。

    撤销与重做

    撤销范围包括对象添加 / 删除 / 变换 / 样式修改、文本内容修改、图层顺序、视点添加 / 更新 / 删除 / 排序 / 命名 / 时长、作品标题与设置。不进入撤销栈的包括：相机浏览、选择变化、保存状态、演示播放。至少保留 50 步ASSUMPTION；执行新编辑后清空重做栈。快捷键为 Ctrl / Cmd + Z 与 Ctrl / Cmd + Shift + Z。

    恢复

    重新打开作品时恢复到最后一次成功保存的内容与编辑视图；选中状态清空。撤销 / 重做栈不跨会话保留，重新打开后从空历史开始。若上次保存失败，作品保留最后成功保存的版本，并在顶栏继续显示失败状态。

    异常

    触发用户可见行为
    本地存储空间不足保存状态变为失败，提示「本地空间不足」；提供重试与导出工程，不静默丢弃改动。
    保存失败且用户尝试离开浏览器原生确认提示；用户可选择留下并重试，或导出工程后离开。
    同一作品在第二个标签页打开第二个标签页以只读方式打开并提示「该作品已在另一窗口编辑」；不写入、不覆盖。
    页面在保存过程中被关闭下次打开恢复最后成功保存的版本；顶栏提示上次未完成保存，但不阻塞编辑。
    FR-07

    导入与导出

    PORTABILITY

    目的

    让作品成为用户可以带走的东西：一个文件包含全部内容与素材，不依赖账号、链接或原设备。

    导出

    顶部「导出」生成单个 .slide 工程文件，文件名取作品标题（非法字符替换为下划线），并附带导出日期。文件包含作品结构、视点路径与全部图片素材，可离线打开；导出不改变作品状态，也不触发额外保存。导出成功显示「已导出 · 文件名 · 大小」；失败时提示原因，作品保持不变。

    导入

    首页「导入」与空状态入口均可选择 .slide 文件。校验通过后创建一个新作品并进入编辑器，不覆盖已有作品；标题重复时追加「（2）」等序号。导入失败时不创建任何作品、不修改现有列表。

    校验项失败行为
    文件类型与完整性提示「不是有效的 .slide 工程文件」，保留文件选择入口。
    工程版本文件版本高于当前应用时提示「请升级后再打开」；低于当前版本时按兼容规则读取。
    必备字段与对象类型指出缺失或未知的类型，整份文件拒绝导入，不做部分恢复。
    素材可用性缺失素材以占位图导入并逐项提示，其余内容正常打开。
    文件大小超过 200MBASSUMPTION 时拒绝并提示上限。

    边界

    P0 不提供只读分享链接、自包含 HTML 导出、PDF 快照与 PPTX 互转。分享能力进入 P1 后需单独定义发布、权限、撤回与失效行为，不与工程文件混为一谈。

    异常

    触发用户可见行为
    工程文件损坏拒绝导入并说明无法解析；现有作品与首页列表不受影响。
    导入过程中取消关闭文件选择或进度，不创建作品。
    导出文件过大提示文件大小与浏览器限制，建议压缩图片后重试；作品不变。

    共享规则

    SHARED RULES

    以下规则被多个模块引用，在此定义一次，模块内只引用编号。任何实现与原型都必须与此保持一致。

    SR-01

    空间坐标、深度与取景

    CANONICAL

    坐标系　X 向右为正，Y 向下为正，Z 朝向观众为正。对象尺寸、位置与深度使用同一套场景单位；负坐标允许存在。界面上只显示缩放比例，不显示坐标轴数值。

    深度与层级　Z 越大越靠近观众，遮挡关系由 Z 决定，而不是由添加顺序决定。左侧对象列表按 Z 从大到小排列。拖拽排序时交换被移动对象与目标位置对象的 Z 值，使顺序稳定且可逆。

    初始视图　新建作品的初始相机位于场景正前方，看向原点，取景为 16:9 安全框。重置视图即回到该状态。

    取景一致性　编辑、视点捕获与演示共用 16:9 安全框；窗口比例不同时等比缩放并留黑，任何比例下都不裁切安全框内的内容。

    深度边界　对象 Z 限定在 −10000 至 10000；超出边界的输入收敛到边界，不产生无限远或穿过相机的对象。

    SR-04

    命名与重复

    NAMING

    新作品默认标题「未命名演示」；同名作品允许存在，首页以更新时间区分。导入产生的新作品在标题重复时追加「（2）」「（3）」等最小可用序号。新对象默认名称按类型计数（文本 1、图片 1、矩形 1），删除后不回收序号；名称不要求唯一。

    重命名只改变显示名称，不改变对象标识、路径顺序或文件内容。任何名称为空时，失焦恢复到上一个有效值。

    SR-05

    本地存储与多标签

    STORAGE

    P0 不使用账号与服务端，作品与素材保存在浏览器本地。用户清理浏览器数据、更换浏览器或设备时，作品不会自动跟随；.slide 工程文件是唯一的迁移手段。

    多标签　同一作品只允许一个标签页写入。检测到第二个标签页打开同一作品时，后者进入只读模式：可查看与演示，不显示编辑工具，不写入数据，并提示「该作品已在另一窗口编辑」。关闭原标签页后刷新即可恢复编辑。

    删除　删除作品同时移除其本地数据与素材，不保留副本；确认框必须明确这一后果。P0 不提供回收站或延迟删除。

    SR-06

    动效与无障碍

    MOTION / A11Y

    所有相机过渡使用缓入缓出；演示中的过渡时长以目标视点为准。系统启用「减少动态效果」时，所有相机过渡立即完成，不以动画作为唯一的信息载体。

    P0 的主路径必须可以只用键盘完成：新建、编辑文本、捕获视点、进入演示、前进 / 后退、退出。控件具备可见焦点；图片对象在 P0 不要求替代文本，但不得把关键信息只放在图片中而不提供文字说明位。

    不出现闪烁或快速重复运动；演示进度、当前视点与保存状态都以文字或图形同时表达，不只依赖颜色。

    术语表

    GLOSSARY
    场景空间
    一个作品中所有内容对象共享的三维坐标环境。
    内容对象
    文本、图片或形状；属于作品，不属于某个视点。
    视点
    相机看向点、距离与朝向的快照；不包含内容。
    路径
    按轨道顺序排列的视点序列；P0 为线性、单向。
    当前视图
    编辑器此刻的相机状态；可用于捕获视点或作为演示起点。
    自由浏览
    演示中临时缩放与环绕，不写回作品；回到路径后恢复。
    工程文件
    .slide 单文件，内含结构与全部素材，用于迁移与备份。
    取景安全框
    16:9 的可见范围；编辑与演示都以此为准，不裁切内容。
